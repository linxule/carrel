# Migration: 0.3.0 → 0.4.0

## What's New

- **Scheduled automation** — overnight vault maintenance via Desktop App local scheduled tasks
- **Graduated trust model** — four levels: Advisory, Consultative, Delegated (experimental), Partnership (experimental)
- **Batch processing** — `/carrel-batch` converts/transcribes entire folders of files
- **Research self-portrait** — `/carrel-mirror` synthesizes your research patterns across the vault
- **Analytical threads** — `notes/threads/` for exploring material through different theoretical lenses
- **Morning briefs** — overnight agent writes `_meta/briefs/YYYY-MM-DD.md` summarizing overnight work
- **Pending decisions/approvals** — structured human-in-the-loop workflows for overnight processing
- **Active plan tracking** — `_meta/plans/` with frontmatter status, surfaced at session start

## What Changed

- `ResearcherProfile` now has an `automation` field (backward compatible — defaults to disabled)
- Session-start hook surfaces morning briefs, active plans, and pending decisions/approvals (only if `_meta/briefs/` exists — no noise for non-automated vaults)
- `last_session_start` is now tracked in `.carrel/plugin-state.json`
- Hook timeout increased from 10s to 15s
- `vault-ops` skill extended with analytical threads knowledge
- `research-partner` agent extended with awareness of plans, threads, briefs, and pending items
- `environment-setup` skill extended with Step 9 automation opt-in

## Automatic Migrations

These run silently with no user action:

1. **Update plugin-state.json**: Version bumped to 0.4.0, `last_session_start` field added
2. **ResearcherProfile compatibility**: Existing `environment.json` requires no changes — `automation` field defaults to disabled

## Manual Steps

1. **Set up overnight automation** (optional): Run `/carrel-automate` to configure scheduled vault maintenance. Choose your trust level — start with Advisory if you're new to automation.

2. **Update vault CLAUDE.md** (if enabling automation): After running `/carrel-automate`, check that your vault `CLAUDE.md` reflects your automation preferences. The setup flow will prompt you, but review it to make sure it matches your intent.

## No Action Required If

- You don't want automated overnight vault maintenance — the new features are fully opt-in
- Your existing commands (`/carrel-convert`, `/carrel-status`, etc.) work normally
- You're not using `_meta/plans/` or `notes/threads/` — these directories are created on demand
