# Migration: 0.1.0 → 0.3.0

## What's New

- Plugin is now distributed via GitHub marketplace (`linxule/carrel`)
- Automatic updates via `claude plugin update carrel@carrel`
- Version tracking — Carrel detects when it's been updated and offers migration

## What Changed

- Plugin manifest simplified (auto-discovery for commands, agents, skills)
- Hook matchers updated from empty string to wildcard
- No changes to environment.json format, vault structure, or commands

## Automatic Migrations

These run silently with no user action:

1. **Create version marker**: Write `.carrel/plugin-state.json` with current version
2. **Verify environment.json**: Confirm existing config is compatible (both flat and nested formats still supported)

## Manual Steps

If you were previously using an AirDrop/local copy:

1. The old local plugin can be removed — the marketplace version replaces it
2. No vault changes needed — your research environment is unchanged
3. Future updates: the plugin will notify you at session start when a new version is available

## No Action Required If

- Your vault and environment.json are working normally
- Commands like `/carrel-status` and `/carrel-convert` work
- You're already on the marketplace version
