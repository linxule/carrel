# 0.9.1 → 0.10.0

Minor release. Carrel now installs beyond Claude Code: the portable skill is
packaged as a cross-host plugin for GitHub Copilot, Codex and Kimi Code, and as
a ZIP for the Claude app. Nothing in your vault changes.

## What's new

- Cross-host plugin at `plugins/carrel/`, generated from `skills/carrel/`:
  - GitHub Copilot (app, VS Code, CLI): add the `linxule/carrel` marketplace, then install `carrel@carrel`
  - Codex (ChatGPT desktop app and CLI): `codex plugin marketplace add linxule/carrel`, then install from **Plugins**
  - Kimi Code (desktop and CLI): **Settings** > **Plugins**, or `/plugins install https://github.com/linxule/carrel`
- Claude app (web or desktop): download `carrel.zip` from the `skill-latest` release and upload it in **Customize** > **Skills**. The ZIP is rebuilt automatically whenever the skill changes.
- README and self-setup guide rewritten in plain English, with install routes with and without a terminal for every app.

## What changed

- The portable skill no longer stands itself down when the `carrel` CLI is installed on the machine. It defers only inside a Claude Code session where the Carrel plugin is active. Before this, Codex, Copilot and Kimi users who had run `install.sh` got a skill that told the agent not to use it.
- GitHub sign-in is optional. The repository is public, so `install.sh` and `install.ps1` no longer stop when you are not signed in. `bootstrap.sh` now hands off to `install.sh`.
- Cowork is now part of the regular Claude app. Scheduling guidance points to Claude's **Scheduled** page. `skills/automation/references/cowork-scheduling-guide.md` is renamed `claude-scheduling-guide.md`.
- Portable runtime: the first reflection of the day is seeded from `_templates/reflection.md`, and the feedback digest collects nested sources and uses the same header as the typed CLI.
- Locked dependencies upgraded to clear security advisories (pillow 13.0.0, urllib3 2.8.0, anyio 4.16.0, certifi 2026.10.23).

## Automatic steps

None. Vault files, profiles and setup state are unchanged.

## Manual steps (optional)

1. Update the `carrel` CLI so the plugin's hooks and commands match this release:

   ```bash
   uv tool upgrade carrel
   ```

2. If you set up a scheduled task while it was called a Cowork task, it keeps working. Find it on the **Scheduled** page in Claude.

## No action required if

- You only use Carrel inside Claude Code and have not scheduled automation.
