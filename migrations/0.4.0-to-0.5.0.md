# Migration: 0.4.0 → 0.5.0

## What's New

- **Knowledge wiki** — optional agent-maintained synthesis layer inside the vault. Compiles interlinked entity and concept pages from your sources. Trust-gated: emerges through graduated trust, not setup-time config.
- **Researcher callouts** — add `> [!researcher]` annotations to wiki pages. Claude reads and respects them, never overwrites.
- **Wiki insights in briefs** — morning briefs now include one-sentence synthesis when wiki is active, not just counts.
- **"Field voice / my voice" framing** — wiki = what your sources say; your notes = what you think. The gap is your contribution.
- **Wiki maintenance automation** — optional `wiki_maintenance` capability in overnight runs. Processes new papers into wiki pages, runs consistency checks.

## What Changed

- `ResearcherProfile` now has `wiki_enabled`, `wiki_preference`, and `wiki_proposal_deferred_until` fields (backward compatible — all default to False/None)
- `AutomationConfig` now has `wiki_maintenance` field (backward compatible — defaults to False)
- Session-start hook surfaces wiki status from morning briefs and falls back to direct page count when no brief exists
- Research-partner skill and agent check `wiki/SCHEMA.md` before prioritizing wiki content
- `/carrel-automate` offers `wiki_maintenance` when wiki is active
- Capability registry tracks upstream sources (Karpathy gist + Hermes Agent) for quarterly review

## Automatic Migrations

These run silently with no user action:

1. **Update plugin-state.json**: Version bumped to 0.5.0
2. **ResearcherProfile/AutomationConfig compatibility**: Existing `environment.json` requires no changes — all new fields have safe defaults

## Manual Steps

1. **Activate the wiki** (optional): Claude will propose a field map when you have 15+ papers and ask cross-source questions. Or ask directly: "set up a knowledge wiki for me." You can also enable `wiki_maintenance` in `/carrel-automate` once the wiki is active.

2. **Learn the callout convention** (if using wiki): Add `> [!researcher]` notes to any wiki page you disagree with or want to annotate. Claude reads these and works around them.

## No Action Required If

- You don't want a knowledge wiki — the feature is fully opt-in and trust-gated
- Your existing commands and automation work normally
- The `wiki/` directory is only created when you activate the wiki
