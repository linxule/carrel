# 0.7.1 → 0.8.1

Minor release. Adds `/carrel-teammates` and the `model-teammates` skill for Codex (ChatGPT), Gemini, and Kimi integration via their community CC plugins. Additive throughout.

## What's new

- **`/carrel-teammates`** — add, remove, or review multi-model teammates. Delegates to the `model-teammates` skill.
- **Interview beat + `/carrel-setup` Phase 5b** — proactive surfacing during onboarding (state-neutral).
- **Profile field** — `model_teammates: dict[str, ModelTeammateStatus]` on `ResearcherProfile`. Statuses: `configured | interested | skipped`.
- **Dashboard** — `_meta/my-environment.md` shows a "Model teammates" line in the Setup block.

## Automatic steps

None — additive schema extension. Existing vaults keep working.

## Design notes

Scope was trimmed three times during review. Dropped: a code-level policy module, vendored install references, a CLAUDE.md marker, a cheat-sheet section, and a 4th enum value (`removed`). The final shape is a thin wrapper — skill-level sensitivity guidance, skill-level install pointers to upstream READMEs, profile state memory, one-line dashboard surface. Claude reads upstream READMEs on demand if install details have drifted.
